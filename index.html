IMPORTAZIONE LOCALE

Importa aziende da CSV

Associa le colonne e controlla l’anteprima. Le corrispondenze con aziende esistenti sono escluse finché scegli Aggiorna. I campi vuoti non cancellano dati esistenti. Referenti aggiuntivi, opportunità e categorie non vengono importati da CSV: usa il backup JSON per un ripristino completo.

Sono supportati file UTF-8 separati da punto e virgola, virgola o tabulazione. Esporta prima un backup JSON se vuoi conservare una copia dei dati attuali.
